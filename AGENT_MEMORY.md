## Gotchas
- Pi SDK: use `@earendil-works/pi-coding-agent` and `@earendil-works/pi-ai` 1.1.x, exact pins. SDK sessions do not load MCP/codemode automatically: add `createMcpExtension()`, `createCodemodeExtension()`, `createToolSearchExtension()` to `DefaultResourceLoader.extensionFactories` and call `session.bindExtensions()` (Pi docs `sdk.md`, example `examples/sdk/14-codemode-mcp.ts`).
- Studium patched a slow streamed tool-argument JSON parse in pi-ai 1.0.0 (`patches/`). Check whether 1.1 still needs it before copying the patch.
- Tectonic is not installed on the owner's host; Docker image will include it. `pdftotext` (poppler) is available.
- Vita lives inside the parent repo `project-remote/` as its own nested git repo; run git commands with `-C /home/krishna/project-remote/vita` or from inside it.
- **Biome via rtk:** the host's rtk hook prints `Linter process terminated abnormally` for biome; run `rtk proxy pnpm exec biome check <files>` to see real output. Biome uses `.gitignore` (vcs enabled).
- Root `pnpm vita …` runs `tsx` inside `cli/` (cwd is `cli/`), so pass absolute or cli-relative paths.
- Zod 4: object defaults that contain arrays need explicit array values in `.default({...})`.
- **rtk hides git exit codes and output** in chained commands. Orchestrator: use `rtk proxy git …` and `git -c commit.gpgsign=false merge …` (merges are signed by default on this host).
- **Tectonic runs with `--only-cached`** in the sandbox (no network during compiles). Any new LaTeX package must be warmed into the cache first by a trusted compile without `--only-cached` (planned `vita setup`). Templates use `microtype` and `\setlength{\parindent}{0pt}` (owner rule).
- Nunjucks 3.2.4 has no `map` filter; use `join(", ", "title")`. Template delimiters: `((( var )))`, `((* tag *))`, `((= comment =))`.
- PDF extraction can split words (microtype/kerning: "T rained"); `checkRender` compares with all whitespace removed. Never reword fixtures to dodge a checker bug — fix the checker.
- Codex tool limits (from Studium): `rm -rf` on computed paths is rejected; put test data under a temp dir. If `apply_patch` fails, write the file with a heredoc.
