Read this before starting. It saves you re-exploring the repo.

- what changed (files)

The orchestrator keeps the rest of this file current. When something under "Open gaps" is fixed, it moves to "Recently done" with the commit. Do not paste code here. Do not store secrets.

## Owner and how we work
- The owner is a sole developer building Vita as an open-source (AGPL-3.0) resume studio. The owner's own resume repo (`<personal-resume-dir>/`, parent folder) is the first real dataset; it is personal and never committed here.
- **Orchestrator:** an orchestrator agent (any capable model).
  - Plans in `docs/plans/YYYY-MM-DD-*.md`, task prompts in `docs/prompts/<task>.md`.
  - Asks the owner whether to run a prompt themselves or have it dispatched.
  - Reviews, verifies, commits and merges. Pushes to GitHub only when the owner asks.
- **Implementers** do exactly the prompt. If it doesn't fit the code, stop and report file:line.
  - Never load orchestration skills. Never spawn workers. Never commit or push.
  - Never touch `.env*`, local agent tooling folders, or the owner's personal files in the parent folder.
- **Model routing** (`scripts/agents/dispatch.sh` aliases):
  - `sol61` (GPT-6.1 Sol) for backend and high-scope tasks (engine, schemas, pipeline, sandbox, security).
  - `fast` (DeepSeek 4.1 Flash) for quick fixes and read-only exploration before a frontend agent prompt.
  - `precise` (GLM 5.3 Flash) for tightly scoped light fixes only; slow.
  - `luna` (GPT-6 Luna, xhigh) for dead-simple fixes.
  - **Frontend split (owner rule):** Codex does frontend setup and plumbing (Vite/Tailwind/shadcn scaffold, routing, API client, query hooks, simple screens). **the frontend agent** (frontend agent) does the critical frontend: the job resume workspace (resume + chat + click-to-edit), the Me outline editor, base resumes, and the final polish pass. UI uses **shadcn/ui** components. One frontend agent session per milestone.
  - Only one GLM run at a time (429s).
- Design: `docs/design/vita-draft.html` (visual draft v0.5). Spec: `docs/specs/2026-10-09-vita-design.md`.
- Owner's design preferences: simple surface, deep core; keep the outline → master → base → job philosophy; no hard-coded professions.

## Gotchas
- Pi SDK: use `@earendil-works/pi-coding-agent` and `@earendil-works/pi-ai` 1.1.x, exact pins. SDK sessions do not load MCP/codemode automatically: add `createMcpExtension()`, `createCodemodeExtension()`, `createToolSearchExtension()` to `DefaultResourceLoader.extensionFactories` and call `session.bindExtensions()` (Pi docs `sdk.md`, example `examples/sdk/14-codemode-mcp.ts`).
- Studium patched a slow streamed tool-argument JSON parse in pi-ai 1.0.0 (`patches/`). Check whether 1.1 still needs it before copying the patch.
- Tectonic is not installed on the owner's host; Docker image will include it. `pdftotext` (poppler) is available.
- Vita lives inside the parent repo `project-remote/` as its own nested git repo; run git commands with `-C <repo>` or from inside it.
- **Biome via rtk:** the host's rtk hook prints `Linter process terminated abnormally` for biome; run `rtk proxy pnpm exec biome check <files>` to see real output. Biome uses `.gitignore` (vcs enabled).
- Root `pnpm vita …` runs `tsx` inside `cli/` (cwd is `cli/`), so pass absolute or cli-relative paths.
- Zod 4: object defaults that contain arrays need explicit array values in `.default({...})`.
- **rtk hides git exit codes and output** in chained commands. Orchestrator: use `rtk proxy git …` and `git -c commit.gpgsign=false merge …` (merges are signed by default on this host).
- **Tectonic runs with `--only-cached`** in the sandbox (no network during compiles). Any new LaTeX package must be warmed into the cache first by a trusted compile without `--only-cached` (planned `vita setup`). Templates use `microtype` and `\setlength{\parindent}{0pt}` (owner rule).
- Nunjucks 3.2.4 has no `map` filter; use `join(", ", "title")`. Template delimiters: `((( var )))`, `((* tag *))`, `((= comment =))`.
- PDF extraction can split words (microtype/kerning: "T rained"); `checkRender` compares with all whitespace removed. Never reword fixtures to dodge a checker bug — fix the checker.
- Scratch workspaces: use unique folder names; agents reusing `scratchpad/ws` overwrote each other's data.
- Codex tool limits (from Studium): `rm -rf` on computed paths is rejected; put test data under a temp dir. If `apply_patch` fails, write the file with a heredoc.
