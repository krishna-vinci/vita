# Vita

An open-source, self-hosted resume studio. Keep one honest outline of your work. Paste a job and get a tailored resume, checked line by line against your real evidence, as Markdown and a LaTeX-compiled PDF, with interview prep.

**Status:** design stage. See [`docs/specs/2026-10-09-vita-design.md`](docs/specs/2026-10-09-vita-design.md) and the visual draft in [`docs/design/vita-draft.html`](docs/design/vita-draft.html).

## Principles in brief

- Truth over polish: no invented employers, skills, numbers or outcomes.
- Every claim has a receipt, and a separate model checks every line.
- Facts once, resumes many: outline → master → base resumes → job resumes.
- Your files, your models: plain files in a git repo you own; any model provider.
